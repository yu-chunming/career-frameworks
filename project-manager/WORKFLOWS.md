# 项目经理工作流程模板

## 一、项目启动流程

```yaml
workflow: project_init
steps:
  - name: 需求确认
    outputs:
      - 项目目标
      - 范围边界
      - 成功标准
  
  - name: 团队组建
    items:
      - 角色分工
      - 职责明确
      - 沟通机制
  
  - name: 计划制定
    items:
      - 里程碑规划
      - 任务分解
      - 资源分配
      - 风险识别
  
  - name: 启动会议
    outputs:
      - 目标对齐
      - 计划确认
      - 启动信号
```

---

## 二、日常管理流程

```yaml
workflow: daily_management
steps:
  - name: 每日站会
    items:
      - 昨日完成
      - 今日计划
      - 问题阻碍
  
  - name: 进度跟踪
    actions:
      - 任务状态更新
      - 风险监控
      - 问题跟进
  
  - name: 沟通协调
    items:
      - 团队沟通
      - 跨部门协调
      - 上级汇报
  
  - name: 问题解决
    process:
      - 问题识别
      - 方案制定
      - 执行跟进
```

---

## 三、每日工作流

### 早间 (09:00-10:00)
```
□ 检查项目状态
□ 准备站会内容
□ 回顾今日重点
```

### 上午 (10:00-12:00)
```
□ 每日站会
□ 问题跟进解决
□ 项目推进
```

### 下午 (14:00-17:00)
```
□ 会议协调
□ 跨部门沟通
□ 文档工作
```

### 晚间 (17:00-18:00)
```
□ 进度汇总
□ 明日计划
□ 邮件回复
```
