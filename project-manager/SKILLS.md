# 项目经理框架完整技能清单

## 一、文档撰写 (writer)

**来源**: ClawHub  
**安装**: `openclaw skill install writer`

### 学习路径
1. 项目文档结构 - 规范格式
2. 清晰表达技巧 - 简洁明了
3. 报告撰写 - 进度汇报

### 文档类型
```
- 项目计划书
- 进度报告
- 会议纪要
- 风险报告
- 总结报告
```

## 二、自动化工具 (python)

**来源**: ClawHub

## 三、会议纪要 (summarize)

**来源**: ClawHub  
**安装**: `openclaw skill install summarize`

### 学习路径
1. 会议要点提取 - 核心内容
2. 行动项整理 - 待办事项
3. 决议记录 - 结论存档

### 会议纪要结构
```
1. 会议信息
2. 讨论要点
3. 决议结论
4. 行动项（责任人/时间）
5. 下次会议
```
