# 设计师职业学习框架

> 本框架完全独立，可直接交给 OpenClaw 学习使用。

---

## ⚡ 快速启动

```
对 OpenClaw 说：

"请学习当前目录下的所有文件：
1. 先阅读 SAFETY-RULES.md 安全红线并严格遵守
2. 阅读 career-config.json 理解框架配置
3. 阅读 SKILLS.md 了解技能详情
4. 阅读 WORKFLOWS.md 掌握工作流程
5. 阅读 MEMORY-SYSTEM.md 理解记忆机制

学习完成后回复：我已学习设计师框架，将遵守安全红线，按框架运行。"
```

- 🚫 禁止删除任何设计文件
- 🔐 设计稿敏感信息需确认
- 📤 上传设计稿需确认
