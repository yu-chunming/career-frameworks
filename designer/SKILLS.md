# 设计师框架完整技能清单

## 一、前端设计 (frontend-design)

**来源**: Anthropic  
**安装**: `openclaw skill install frontend-design`

### 学习路径
1. 设计系统理解 - 设计规范、组件库
2. 组件库使用 - 常用UI组件
3. 交互设计原则 - 用户体验
4. 原型快速实现 - 快速出图

### 设计检查表
```
□ 是否符合设计规范？
□ 视觉层级是否清晰？
□ 交互是否流畅？
□ 是否考虑响应式？
□ 是否有无障碍考虑？
```

## 三、设计文档 (writer)

**来源**: ClawHub
