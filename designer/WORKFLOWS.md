# 设计师工作流程模板

## 一、设计流程

```yaml
workflow: design_process
steps:
  - name: 需求理解
    outputs:
      - 设计目标
      - 用户群体
      - 使用场景
  
  - name: 灵感收集
    sources:
      - 设计网站
      - 竞品分析
      - 流行趋势
  
  - name: 设计执行
    items:
      - 信息架构
      - 交互设计
      - 视觉设计
  
  - name: 设计评审
    checks:
      - 需求满足
      - 体验流畅
      - 视觉美观
  
  - name: 修改迭代
    actions:
      - 收集反馈
      - 优化调整
      - 最终确认
  
  - name: 交付输出
    outputs:
      - 设计稿
      - 标注文档
      - 切图资源
```

---

## 二、每日工作流

### 早间 (09:00-10:00)
```
□ 浏览设计趋势
□ 收集设计灵感
□ 回顾今日任务
```

### 上午 (10:00-12:00)
```
□ 设计执行
□ 产出设计稿
□ 内部评审
```

### 下午 (14:00-17:00)
```
□ 修改迭代
□ 协作沟通
□ 交付输出
```

### 晚间 (20:00-22:00)
```
□ 技能学习
□ 作品打磨
□ 案例研究
```
