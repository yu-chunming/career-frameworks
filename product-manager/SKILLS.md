# 产品经理框架完整技能清单

## 一、前端设计 (frontend-design)

**来源**: Anthropic  
**安装**: `openclaw skill install frontend-design`

### 学习路径
1. 设计系统理解 - 设计规范、组件库
2. 组件库使用 - 常用UI组件
3. 交互设计原则 - 用户体验
4. 原型快速实现 - 快速出图

### 产品设计检查表
```
□ 是否符合用户习惯？
□ 交互是否流畅？
□ 信息层级是否清晰？
□ 是否有视觉引导？
□ 是否考虑边界情况？
□ 是否有无障碍考虑？
```

---

## 二、数据分析 (python)

**来源**: ClawHub  
**安装**: `openclaw skill install python`

### 学习路径
1. 数据采集处理 - 数据获取
2. 指标计算分析 - 核心指标
3. 数据可视化 - 图表输出
4. 洞察提取 - 数据驱动决策

### 常用分析维度
```
- 用户数据：DAU、MAU、留存率
- 行为数据：转化漏斗、路径分析
- 业务数据：GMV、ARPU、ROI
```

## 四、内容摘要 (summarize)

**来源**: ClawHub  
**安装**: `openclaw skill install summarize`

### 学习路径
1. 用户反馈提炼 - 关键问题提取
2. 竞品分析整理 - 核心差异对比
3. 会议纪要生成 - 要点记录

### 应用场景
```
- 用户反馈汇总
- 竞品分析报告

- 迭代总结
```
