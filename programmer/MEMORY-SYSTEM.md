# 🧠 记忆备份机制

> 本框架内置三层记忆体系，每日自动总结进化。

---

## 一、三层记忆体系

| 层级 | 名称 | 说明 | 存储位置 |
|:---|:---|:---|:---|
| **L1** | 工作记忆 | 当前会话上下文 | 会话临时存储 |
| **L2** | 短期记忆 | 近期重要事件 | `memory/YYYY-MM-DD.md` |
| **L3** | 长期记忆 | 核心知识经验 | `MEMORY.md` |

---

## 二、每日记忆流程

### 触发时间：每天 24:00（0:00）

### 执行步骤：

```
第一步：回顾会话历史
├── 读取今日所有会话记录
├── 提取关键事件和决策
└── 识别重要学习点

第二步：提取有效信息
├── 用户提到的重要信息
├── 成功解决问题的方法
├── 失败的尝试和原因
└── 新学到的知识

第三步：总结用户习惯
├── 偏好的代码风格
├── 常用的工具/框架
├── 沟通方式偏好
└── 关注的技术方向

第四步：判断固化技能
├── 是否有重复使用3次以上的能力？
├── 是否解决了通用问题？
├── 是否可以标准化？
└── 如满足，创建新技能

第五步：生成进化报告
├── 今日数据统计
├── 学会的新东西
├── 犯的错误
├── 可固化的技能
└── 明日改进计划
```

---

## 四、固化技能判断标准

同时满足以下条件，判断为可固化：

| 条件 | 说明 |
|------|------|
| 重复使用 ≥ 3次 | 同一能力多次使用 |
| 解决通用问题 | 不是一次性问题 |
| 可以标准化 | 有明确的执行步骤 |
| 有价值 | 能提升效率或质量 |

---

## 五、固化流程

```
识别可固化技能
    ↓
创建 skill 目录
    ├── SKILL.md（技能说明）
    └── examples/（示例）
    ↓
编写技能文档
    ↓
测试技能功能
    ↓
安装到 skills/ 目录
    ↓
更新 MEMORY.md
```

---

## 六、记忆维护规则

### 每周回顾（周日）

```
1. 回顾本周所有短期记忆
2. 提取核心经验到长期记忆
3. 删除过时信息
4. 更新用户习惯档案
```

### 长期记忆更新规则

写入 `MEMORY.md` 的内容：
- 重要的决策和经验
- 反复使用的知识
- 用户习惯档案
- 避免重复犯的错误
- 已固化的技能列表

---

## 七、目录结构

```
[框架目录]/
├── memory/              # 短期记忆目录
│   └── YYYY-MM-DD.md    # 每日记忆文件
├── MEMORY.md            # 长期记忆文件
├── data/                # 数据目录
│   └── evolution-reports/  # 进化报告
│       └── YYYY-MM-DD.md
└── skills/              # 固化技能目录
    └── [skill-name]/
        └── SKILL.md
```

---

## 八、定时任务配置

在 `career-config.json` 中添加：

```json
{
  "cron_tasks": [
    {
      "name": "daily-memory-backup",
      "schedule": "0 0 * * *",
      "timezone": "Asia/Shanghai",
      "action": "每日记忆备份与进化报告",
      "enabled": true
    },
    {
      "name": "weekly-memory-review",
      "schedule": "0 20 * * 0",
      "timezone": "Asia/Shanghai",
      "action": "每周记忆回顾与长期记忆更新",
      "enabled": true
    }
  ]
}
```

## 九、安全提醒

记忆备份时注意：
- 🚫 不记录密码、密钥等敏感信息
- 🔐 敏感数据用 `***` 替代
- ✅ 只记录有价值的信息
- ✅ 定期清理过时记忆
