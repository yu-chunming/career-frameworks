```

"请学习当前目录下的所有文件：
1. 先阅读 SAFETY-RULES.md 安全红线并严格遵守

```

## 🧠 记忆备份机制

详见 [MEMORY-SYSTEM.md](./MEMORY-SYSTEM.md)

| 任务 | 时间 | 说明 |
|------|------|------|
| 每日记忆备份 | 24:00 | 回顾会话、提取信息、总结习惯、判断固化技能 |
