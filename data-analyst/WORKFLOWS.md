# 数据分析师工作流程模板

## 一、数据分析流程

### 执行步骤

```yaml
workflow: data_analysis
steps:
  - name: 需求理解
    outputs:
      - 分析目标
      - 关键问题
      - 预期输出
  
  - name: 数据获取
    sources:
      - 数据库查询
      - 文件导入
      - API调用
  
  - name: 数据清洗
    actions:
      - 缺失值处理
      - 异常值检测
      - 数据类型转换
      - 格式标准化
  
  - name: 探索分析
    items:
      - 描述性统计
      - 分布分析
      - 相关性分析
  
  - name: 深度分析
    methods:
      - 趋势分析
      - 对比分析
      - 细分分析
  
  - name: 结果输出
    outputs:
      - 数据可视化
      - 分析报告
      - 洞察建议
```

---

## 二、报告撰写流程

### 执行步骤

```yaml
workflow: report_writing
steps:
  - name: 结构规划
    sections:
      - 摘要
      - 背景
      - 方法
      - 结果
      - 建议
  
  - name: 数据整理
    items:
      - 关键指标
      - 核心图表
      - 重要发现
  
  - name: 内容撰写
    practices:
      - 结论先行
      - 数据支撑
      - 逻辑清晰
  
  - name: 审核优化
    checks:
      - 数据准确性
      - 逻辑完整性
      - 表达清晰度
```

## 三、每日工作流

### 早间例行 (09:00-10:00)

```
□ 检查核心数据指标
□ 监控数据异常
□ 回顾今日任务
□ 确认分析需求
```

### 上午工作 (10:00-12:00)

```
□ 数据提取处理
□ 数据清洗验证
□ 探索性分析
□ 问题记录
```

### 下午工作 (14:00-17:00)

```
□ 深度分析
□ 可视化输出
□ 报告撰写
□ 结果汇报
```

### 晚间总结 (17:00-18:00)

```
□ 今日工作总结
□ 待办事项整理
□ 明日计划制定
□ 方法笔记记录
```
