# ⛔ 安全红线

> **重要**：使用本框架前必须阅读并遵守以下规则。

---

## 一、文件操作红线

| 操作 | 规则 |
|------|------|
| 删除数据文件 | 🚫 **绝对禁止** |
| 删除文件夹 | 🚫 **绝对禁止** |
| 清空文件内容 | 🚫 **绝对禁止** |
| 创建文件 | ✅ 允许 |
| 读取文件 | ✅ 允许 |
| 复制文件 | ✅ 允许 |

---

## 二、敏感信息红线

| 类型 | 规则 |
|------|------|
| 用户数据 | 🔐 需询问确认后处理 |
| 商业数据 | 🔐 需询问确认后处理 |
| 导出数据 | 🔐 导出前需确认 |
| 数据库密码 | 🔐 禁止明文存储 |

**敏感操作流程**：
1. 暂停执行
2. 向用户说明操作内容和风险
3. 等待用户明确确认
4. 确认后才可执行

---

## 三、网络操作红线

| 操作 | 规则 |
|------|------|
| 数据库查询 | ✅ 允许 |
| 导出数据 | ⚠️ 需确认 |
| 发送报告 | ⚠️ 需确认 |
| 上传数据 | ⚠️ 需确认 |

---

## 四、安全使用口诀

```
删文件，说不行；
敏感数据，先确认；
导出数据，问一问；
安全第一，记在心！
```

---

**记住**：数据安全是底线，优先保护用户数据。
