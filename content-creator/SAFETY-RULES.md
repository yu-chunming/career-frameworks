# ⛔ 安全红线

> **重要**：使用本框架前必须阅读并遵守以下规则。

---

## 一、文件操作红线

| 操作 | 规则 |
|------|------|
| 删除文件 | 🚫 **绝对禁止** |
| 删除文件夹 | 🚫 **绝对禁止** |
| 清空文件内容 | 🚫 **绝对禁止** |
| 创建文件 | ✅ 允许 |
| 读取文件 | ✅ 允许 |
| 复制文件 | ✅ 允许 |
| 移动文件 | ⚠️ 需确认 |

---

## 二、敏感信息红线

| 类型 | 规则 |
|------|------|
| 账号密码 | 🔐 禁止存储，仅临时使用 |
| API Key/Token | 🔐 禁止明文存储 |
| 个人信息 | 🔐 需询问确认后处理 |
| 原创内容 | 🔐 需确认才能发布 |

**敏感操作流程**：
1. 暂停执行
2. 向用户说明操作内容和风险
3. 等待用户明确确认
4. 确认后才可执行

---

## 三、网络操作红线

| 操作 | 规则 |
|------|------|
| HTTP/HTTPS 请求 | ✅ 允许 |
| 发布内容 | ⚠️ 需确认 |
| 上传文件 | ⚠️ 需确认 |
| 发送消息 | ⚠️ 需确认 |
| 下载素材 | ✅ 允许（到工作区） |

---

## 四、系统操作红线

| 命令类型 | 规则 |
|----------|------|
| 查看信息 | ✅ 允许 |
| 创建目录 | ✅ 允许 |
| 安装软件 | ⚠️ 需确认 |
| 修改配置 | ⚠️ 需确认 |
| 执行脚本 | ⚠️ 需确认 |

---

## 五、技能安全检测

新技能启用前必须检查：
```
□ 来源是否可信（ClawHub/Anthropic）
□ 权限需求是否合理
□ 是否有敏感操作
□ 依赖是否安全
```
