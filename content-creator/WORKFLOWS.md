# 自媒体工作者工作流程模板

## 一、内容创作流程

### 执行步骤

```yaml
workflow: content_creation
steps:
  - name: 选题策划
    outputs:
      - 内容主题
      - 目标用户
      - 发布平台
      - 预期效果
  
  - name: 素材收集
    actions:
      - 搜索相关资料
      - 收集热点素材
      - 整理数据案例
  
  - name: 内容制作
    parallel:
      - 文案撰写
      - 图片设计
      - 视频剪辑
  
  - name: 质量检查
    checks:
      - 标题吸引力
      - 内容价值
      - 视觉效果
      - 平台适配
  
  - name: 发布优化
    items:
      - 发布时间选择
      - 标签关键词
      - 互动引导
  
  - name: 数据追踪
    metrics:
      - 阅读量
      - 互动率
      - 转化率
```

---

## 二、热点追踪流程

### 执行步骤

```yaml
workflow: trending_content
steps:
  - name: 热点监测
    sources:
      - 微博热搜
      - 抖音热榜
      - 知乎热榜
      - B站热门
  
  - name: 相关性判断
    criteria:
      - 是否与领域相关？
      - 是否有创作空间？
      - 风险评估
  
  - name: 快速产出
    timeline: 2小时内
    outputs:
      - 观点输出
      - 二次创作
  
  - name: 发布推广
    actions:
      - 多平台发布
      - 话题标签
      - 互动回复
```

## 三、周度复盘流程

### 执行步骤

```yaml
workflow: weekly_review
steps:
  - name: 数据汇总
    metrics:
      - 发布数量
      - 阅读总量
      - 互动总量
      - 粉丝增长
  
  - name: 内容分析
    items:
      - 高表现内容特点
      - 低表现内容原因
      - 用户偏好变化
  
  - name: 策略调整
    outputs:
      - 下周选题方向
      - 发布时间优化
      - 内容类型调整
  
  - name: 计划制定
    items:
      - 下周内容日历
      - 重点选题
      - 活动策划
```

## 四、每日工作流

### 早间例行 (07:00-09:00)

```
□ 浏览热点趋势
□ 确定今日选题
□ 收集素材资料
□ 制定发布计划
```

### 内容创作 (09:00-12:00)

```
□ 撰写文案
□ 设计配图
□ 视频剪辑
□ 内容审核
```

### 发布运营 (14:00-18:00)

```
□ 按计划发布内容
□ 多平台分发
□ 回复用户评论
□ 互动引导
```

### 数据复盘 (20:00-22:00)

```
□ 统计今日数据
□ 分析内容效果
□ 调整明日计划
□ 学习优秀案例
```

## 五、内容发布检查表

### 发布前检查

```
□ 标题是否吸引人（15字以内）
□ 封面图是否清晰美观
□ 内容是否完整有价值
□ 是否有行动号召
□ 标签关键词是否准确
□ 发布时间是否合适
```

### 发布后追踪

```
□ 1小时后检查数据
□ 回复热门评论
□ 关注转发互动
□ 记录数据表现
```
