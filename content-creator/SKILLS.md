# 自媒体工作者框架完整技能清单

## 一、写作优化 (writer)

**来源**: ClawHub  
**安装**: `openclaw skill install writer`

### 学习路径
1. 识别AI写作特征 - 机械重复、模式化表达
2. 消除重复句式 - 避免开头雷同、结构相似
3. 增加表达多样性 - 句式变化、词汇丰富
4. 提升文字感染力 - 情感表达、细节描写
5. 形成个人风格 - 独特声音、辨识度

### 内容创作检查表
```
□ 标题是否吸引人？
□ 开头是否有新意？
□ 内容是否有价值？
□ 是否有具体案例？
□ 结尾是否有行动号召？
□ 是否适合目标平台？
```

## 二、内容摘要 (summarize)

**来源**: ClawHub  
**安装**: `openclaw skill install summarize`

### 学习路径
1. 关键信息识别 - 找出核心观点
2. 结构化摘要输出 - 逻辑清晰的表达
3. 多格式支持 - URL/文件/视频
4. 要点提取技巧 - 精准提炼

### 应用场景
```
- 热点内容快速提炼
- 竞品分析摘要
- 素材快速整理
- 行业资讯汇总
```

## 三、数据分析 (python)

**来源**: ClawHub  
**安装**: `openclaw skill install python`

### 学习路径
1. 数据采集处理 - 爬取、清洗
2. 粉丝数据分析 - 用户画像
3. 内容效果统计 - 阅读量、互动率
4. 可视化输出 - 图表生成

### 常用分析维度
```
- 内容数据：阅读量、点赞、评论、转发
- 用户数据：粉丝增长、活跃度、画像
- 效果数据：转化率、留存率
```

## 四、前端设计 (frontend-design)

**来源**: Anthropic  
**安装**: `openclaw skill install frontend-design`

### 学习路径
1. 设计规范理解 - 排版、配色
2. 快速原型实现 - 封面图、配图
3. 组件设计 - 可复用元素
4. 多平台适配 - 不同尺寸

### 设计检查表
```
□ 是否符合平台规范？
□ 封面是否吸引眼球？
□ 配色是否协调？
□ 文字是否清晰可读？
□ 是否有品牌元素？
```
