# 文字工作者框架完整技能清单

## 一、写作优化 (writer)

**来源**: ClawHub  
**安装**: `openclaw skill install writer`

### 学习路径
1. 识别AI写作特征 - 机械重复、模式化表达
2. 消除重复句式 - 避免开头雷同、结构相似
3. 增加表达多样性 - 句式变化、词汇丰富
4. 提升文字感染力 - 情感表达、细节描写
5. 形成个人风格 - 独特声音、辨识度

### AI写作常见问题
```
❌ 开头模式化
   "在当今快速发展的..."
   "随着...的不断发展..."
   
❌ 重复句式
   "不仅...而且..."
   "一方面...另一方面..."
   
❌ 空洞表达
   "具有重要意义"
   "有着深远影响"
```

### 写作优化检查表
```
□ 开头是否有新意？
□ 句式是否多样？
□ 是否有具体细节？
□ 情感是否真实？
□ 是否有个人风格？
```

## 二、内容摘要 (summarize)

**来源**: ClawHub  
**安装**: `openclaw skill install summarize`

### 学习路径
1. 关键信息识别 - 找出核心观点
2. 结构化摘要输出 - 逻辑清晰的表达
3. 多格式支持 - URL/文件/视频
4. 要点提取技巧 - 精准提炼

### 摘要输出格式
```markdown
## 核心观点
- 要点1
- 要点2

## 关键信息
- 数据/案例

## 结论
一句话总结
```
