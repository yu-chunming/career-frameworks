# 🧠 记忆备份机制

---

## 一、三层记忆体系

| 层级 | 名称 | 存储位置 |
|:---|:---|:---|
| L1 | 工作记忆 | 会话临时存储 |
| L2 | 短期记忆 | `memory/YYYY-MM-DD.md` |
| L3 | 长期记忆 | `MEMORY.md` |

---

## 二、每日记忆流程（24:00）

```
1. 回顾会话历史 → 提取关键事件
2. 提取有效信息 → 成功方法、失败原因
3. 总结用户习惯 → 写作风格、关注领域
4. 判断固化技能 → 重复3次+通用+可标准化
5. 生成进化报告 → 发送给用户
```

---

## 三、进化报告格式

```markdown
# 🧬 每日进化报告 - YYYY-MM-DD

## 📊 今日数据
- 会话次数: X次
- 完成文章: X篇
- 学习技能: X个

## 🎓 学会的新东西
1. ...
2. ...

## ⚠️ 犯的错误
1. ...
   - 原因: ...
   - 解决: ...

## 👤 用户习惯总结
- 写作风格偏好: ...
- 关注领域: ...
- 文章类型偏好: ...

## 💡 可固化的技能
1. ...

## 📝 明日改进计划
1. ...
```

---

## 四、固化技能标准

- 重复使用 ≥ 3次
- 解决通用问题
- 可以标准化

---

## 五、目录结构

```
[框架目录]/
├── memory/              # 短期记忆
├── MEMORY.md            # 长期记忆
├── data/evolution-reports/  # 进化报告
└── skills/              # 固化技能
```
