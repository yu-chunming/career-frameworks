# 文字工作者工作流程模板

## 一、文章写作流程

### 执行步骤

```yaml
workflow: article_writing
steps:
  - name: 选题规划
    outputs:
      - 文章主题
      - 目标读者
      - 核心观点
      - 预期效果
  
  - name: 资料收集
    actions:
      - 搜索相关资料
      - 收集数据案例
      - 整理引用来源
  
  - name: 大纲构建
    structure:
      - 引言（吸引注意力）
      - 正文要点（3-5个）
      - 结尾（总结升华）
  
  - name: 初稿撰写
    practices:
      - 快速输出，不纠结细节
      - 跟随思路，一气呵成
      - 控制字数，保持节奏
  
  - name: 编辑修改
    checks:
      - 结构是否完整
      - 逻辑是否清晰
      - 表达是否准确
  
  - name: 校对润色
    items:
      - 语法检查
      - 标点规范
      - 格式统一
  
  - name: 最终定稿
    actions:
      - 通读全文
      - 标题优化
      - 元信息完善
```

## 二、编辑校对流程

### 执行步骤

```yaml
workflow: editing
steps:
  - name: 整体评估
    questions:
      - 文章主题是否明确？
      - 目标读者是否清晰？
      - 核心观点是否突出？
  
  - name: 结构检查
    items:
      - 开头是否吸引人
      - 段落衔接是否自然
      - 结尾是否有力
  
  - name: 内容优化
    actions:
      - 删除冗余内容
      - 补充必要信息
      - 优化表达方式
  
  - name: 语言润色
    checks:
      - 句式多样化
      - 用词准确性
      - 节奏感把握
  
  - name: 细节校对
    items:
      - 语法错误
      - 标点符号
      - 格式排版
```

## 三、素材管理流程

### 素材收集

```
来源          收集方式         处理方法
──────────────────────────────────────────
书籍阅读      摘录金句        按主题分类
文章阅读      收藏链接        添加标签
日常观察      记录灵感        及时整理
访谈交流      录音转文字      提取要点
数据报告      截图保存        标注来源
```

## 四、每日工作流

### 早间 (08:00-10:00)

```
□ 阅读优质内容 30min
□ 收集整理素材
□ 确定今日写作主题
```

### 上午 (10:00-12:00)

```
□ 撰写初稿
□ 保持输出节奏
□ 记录写作难点
```

### 下午 (14:00-17:00)

```
□ 编辑修改上午稿件
□ SEO优化检查
□ 格式排版完善
```

### 晚间 (20:00-22:00)

```
□ 写作练习/模仿
□ 学习优秀作品
□ 记录心得体会
```

## 五、写作质量检查表

### 内容质量

```
□ 主题明确，观点清晰
□ 逻辑严谨，结构完整
□ 论据充分，案例恰当
□ 语言流畅，表达准确
□ 有新意，有价值
```

### 格式规范

```
□ 标题吸引人
□ 段落长度适中
□ 标点使用正确
□ 格式统一美观
□ 无错别字
```

### SEO检查

```
□ 关键词布局合理
□ 标题包含关键词
□ 描述文字完整
□ 内链外链设置
□ 图片alt标签
```
