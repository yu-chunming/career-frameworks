# ⛔ 安全红线

> **重要**：使用本框架前必须阅读并遵守以下规则。

---

## 一、文件操作红线

| 操作 | 规则 |
|------|------|
| 删除文件 | 🚫 **绝对禁止** |
| 删除文件夹 | 🚫 **绝对禁止** |
| 清空文件内容 | 🚫 **绝对禁止** |
| 创建文件 | ✅ 允许 |
| 读取文件 | ✅ 允许 |
| 复制文件 | ✅ 允许 |

---

## 二、敏感信息红线

| 类型 | 规则 |
|------|------|
| 密码 | 🔐 禁止存储 |
| API Key/Token | 🔐 禁止明文存储 |
| 个人信息 | 🔐 需询问确认 |
| 原创作品 | 🔐 需确认才能发布 |

---

## 三、网络操作红线

| 操作 | 规则 |
|------|------|
| 发布内容 | ⚠️ 需确认 |
| 上传作品 | ⚠️ 需确认 |
| 发送邮件 | ⚠️ 需确认 |
| 下载素材 | ✅ 允许 |

---

## 安全使用口诀

```
删文件，说不行；
敏感信息，先确认；
发布内容，问一问；
安全第一，记在心！
```
